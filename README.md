# Computer Course Exam Review Skill

一个面向计算机专业课期末复习的 Codex Skill。它可以根据用户在本地提供的往年真题、复习提纲、课堂笔记和重点标注，整理考点、安排复习计划、生成练习题并解释答案。

## Privacy Boundary

本仓库是公开仓库，只包含 Skill 规则和通用课程分类，不包含任何原始试卷、课件、录音、答案、截图、数据集或从私有资料提取的全文。

使用时，用户在本地或当前会话中提供资料即可。不要将学校资料、学生信息或 GitHub Token 写入仓库。

## Covered Courses

优先覆盖操作系统、计算机网络、计算机组成原理、数据库、数据结构与程序设计、软件工程与 Web、人工智能与机器学习、数字图像处理、数字逻辑和嵌入式系统。
